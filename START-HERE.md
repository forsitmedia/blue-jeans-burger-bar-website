# Blue Jeans Burger Bar — Start Here

Complete bilingual static website built with HTML, CSS and vanilla JavaScript. No framework, package install, build command or backend is required.

## Preview in VS Code

1. Unzip the folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html`.
4. Choose **Go Live** with the Live Server extension.

Portuguese is the default. Use the PT/EN switch in the navigation to open the complete English version.

## Main files

- `index.html`, `menu.html`, `galeria.html`, `historia.html`, `contacto.html` — Portuguese pages
- `en/` — complete English version
- `404.html` — bilingual not-found page
- `assets/css/v2.css` — visual system, layout and responsive rules
- `assets/js/v2.js` — navigation, reveal effects, filters and gallery lightbox
- `assets/data/content.json` — quick reference for verified business/menu data
- `assets/images/photos/` — 25 optimized WebP photos supplied for this concept
- `robots.txt`, `sitemap.xml`, `_headers` — SEO, crawl and hosting files

## Facts to confirm with Blue Jeans

Current official Instagram and the delivery listing use **Rua Costa Pinto 104**; some older directories use number 100. Confirm the door number and postal code before launch.

Menu items and prices were checked against the public Uber Eats listing on 18 August 2026. Delivery prices can differ from dine-in prices. Replace them with the restaurant's final approved menu.

The story about the blue walls, Fernando Matos and Marina Alonso, and the younger concept is based on Time Out Lisboa's Blue Jeans profile. Ask the owners to approve the final wording.

## Images

The active concept uses the photographs supplied by the user. `IMAGE-CREDITS.md` records this. Before a public launch, confirm the restaurant's permission to publish them and retain the original high-resolution files.

## Domain and launch

`https://bluejeansburgerbar.pt/` is a proposed canonical domain. If the chosen domain differs, replace it in every HTML page, `robots.txt` and `sitemap.xml`.

Reservation buttons use the verified phone number. There is no fake form. Directions open Google Maps; social and delivery links open in a new tab.

The folder can be uploaded directly to GitHub Pages, Cloudflare Pages, Netlify or another static host. Upload its contents so `index.html` sits at the public root.
